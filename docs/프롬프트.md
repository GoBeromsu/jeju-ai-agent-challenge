# 프롬프트와 도구 정의

이 문서는 `python3 build/export_prompts.py` 로 코드에서 그대로 뽑았습니다. 숫자·지도·후보 고르기는 모델이 아니라 계산 도구(app/engine.py, app/advisor.py)가 합니다.

## 1. 운영 경로: Gemini (app/agent.py)
- 모델: `gemini-3.8-flash` (환경변수 GEMINI_MODEL 로 바꿈), Google Gen AI SDK `google-genai`
- 모델로 보내는 것: 첫 요청은 사용자 문장과 현재 조건 이름표(업종 이름·손님 방식·지역·동/읍면·경쟁·이웃·성장 여부). 도구를 부르면 답 요청에 도구 결과(남은 후보 수·후보 동네 이름·빠진 이유·보여 준 동네 이름)가 더해진다. 점포 수·인구 같은 숫자는 보내지 않는다. 200자 초과이거나 두 자리 이상 숫자가 3개 이상인 글은 보내지 않는다.
- 모델이 실패하면: "자유 대화를 잠시 쓸 수 없어 정해진 상담 순서로 이어 갈게요." 를 앞에 붙이고 같은 상담 순서(규칙 경로)로 이어 간다.

### 시스템 지시
```text
너는 제주에서 가게를 열려는 40~60대 창업자가 답사할 동네를 좁히도록 돕는 안내자다.
- 사용자의 말을 도구 호출로 바꾼다. 조건을 바꾸려면 set_conditions, 특정 동네를 보려면 show_dong, 처음부터면 reset.
- 숫자(점포 수, 비중, 인구)를 지어내지 않는다. 도구 결과에 있는 남은 후보 수와 동네 이름만 말한다.
- 답은 존댓말로 두 문장 이내, 쉬운 말로 쓴다. 다음에 무엇을 정하면 좋을지 한 가지만 권한다.
- 업종은 사용자가 말한 그대로 business 에 넣는다 (예: 반찬가게, 카페, 미용실).
- 지역 조건을 풀자고 하면 region 또는 area 에 '상관없음'을 넣는다.
- 사용자가 말하지 않은 조건(경쟁 적은 곳, 이웃 가게, 성장 등)을 스스로 넣지 않는다.
- 다음 질문과 후보 설명은 화면의 상담 순서가 한다. 너는 조건만 정확히 옮기고 한 문장으로 받아 준다.
```

### 도구
| 도구 | 인자 |
|---|---|
| `set_conditions` | business, visit(목적|지나가다|모름), region(제주시|서귀포시|상관없음), area(동|읍면|상관없음), competition, neighbors, growing |
| `show_dong` | name |
| `reset` | - |

## 2. 테스트 경로: OpenAI (app/agent_openai.py, 운영 기본값 아님)
- 모델: `gpt-6-luna` (GPT-6 세대 미만 거부), 공식 SDK `openai` + Responses API, store=False
- 한 차례 상한: 모델 호출 2회, 호출마다 출력 400 토큰
- 기록: 모델명·호출 횟수·토큰 수·도구 이름만. 키와 사용자 문장 원문은 남기지 않는다.

### 시스템 지시
```text
너는 제주에서 가게를 열려는 40~60대 창업자가 답사할 동네를 좁히도록 돕는 안내자다.
- 사용자의 말을 도구 호출로 바꾼다. 조건은 set_conditions, 특정 동네는 show_dong, 처음부터는 reset.
- 조건이 서로 부딪히거나(예: 제주시 안에서 서귀포 동네), 업종처럼 꼭 필요한 것이 빠졌으면 ask_clarify 로 한 가지만 묻는다.
- 사용자가 말하지 않은 조건(경쟁 적은 곳, 이웃 가게, 성장)을 스스로 넣지 않는다.
- 이전 조건을 바꾸거나 풀자는 말이면 그 칸만 바꾼다. 지역을 풀면 region 또는 area 에 '상관없음'.
- 숫자(점포 수, 비중, 인구, 유동, 임대료, 매출)를 지어내지 않는다. 답은 존댓말 한두 문장.
```

## 3. 상담 순서 (모델 없이도 같은 흐름, app/advisor.py)

첫 질문: **손님이 주로 어떻게 올 것 같으세요?**

> 답에 따라 보는 지표가 달라져요. 매일 들르는 단골이면 마트·병원 같은 생활 이웃과 점포가 촘촘한 정도를, 일부러 찾아와 머무는 손님이면 숙박 업소와 같은 업종({name}) 가게가 모인 정도를 먼저 봐요.

보기: 매일 들르는 단골 / 일부러 찾아와 머무는 손님 / 아직 모름

| 답 | 비교 기준 | 설명 |
|---|---|---|
| 지나가다 | 매일 들르는 단골 기준 | 단골은 장 보러, 병원 가는 길에 들러요. 그래서 마트·병원·약국·학원(생활 이웃) 수와 점포가 1㎢에 몇 곳인지(촘촘함)를 먼저 봤어요. 같은 업종({name}) 비중은 순위를 정하는 데 조금만 쓰고 주의점으로 따로 적었어요. |
| 목적 | 일부러 찾아와 머무는 손님 기준 | 찾아오는 손님은 여행·나들이 중에 와요. 그래서 숙박 업소 수와 같은 업종({name}) 가게가 모여 있는 정도를 먼저 봤어요. 같은 업종이 모인 곳은 경쟁도 많으니 같은 업종 비중을 주의점으로 적었어요. |

| 답 | 다음 질문 | 이유 |
|---|---|---|
| 지나가다 | 가게 자리로 시내(동 지역)와 읍·면 중 어디가 생활권에 가까우세요? | 단골 장사는 사는 곳과 가까워야 오래 다닐 수 있어요. 답하시면 후보를 그 지역 안에서 다시 골라요. |
| 목적 | 제주시 쪽과 서귀포시 쪽 중 다니시기 편한 곳이 있나요? | 찾아오는 손님 장사는 섬 어디든 될 수 있어서, 사장님이 매일 오가기 편한 쪽으로 좁히는 게 좋아요. |
| 모름 | 두 예 중 어느 쪽이 생각하시는 가게와 더 닮았나요? | 닮은 쪽을 고르시면 그 기준으로 후보를 세 곳까지 골라 드려요. 계속 모르셔도 두 예를 지도에서 비교하실 수 있어요. |
