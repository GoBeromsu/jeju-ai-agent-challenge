# 설치·실행 매뉴얼

## 이번 제출본: 웹 체험과 Docker 재현

- 웹 체험: [제주 동네 답사 에이전트](https://jeju-ai-agent-challenge.vercel.app/)를 브라우저에서 엽니다.
- 로컬 재현: 소스 ZIP을 풀고 `jeju-agent` 폴더에서 `docker compose up --build -d`를 실행한 뒤 `http://127.0.0.1:8765/`을 엽니다. Docker Desktop 또는 Docker Engine과 Compose v2.24 이상이 필요합니다. 첫 이미지 빌드에는 인터넷이 필요합니다.
- `.env` 없이도 로컬 2D 지도와 상담이 동작합니다. 종료는 `docker compose down`입니다.

아래 Windows 절차는 별도로 만든 이전 실행 번들용입니다. 이번 소스 ZIP에는 `실행.bat`과 Windows용 Python이 들어 있지 않습니다.

## 준비물

- Windows 10/11 (64비트) PC. 권장 사양: i7-8700, GTX 1060 3GB 수준 이상
- Chrome 또는 Edge, 화면 1920×1080
- 압축 파일 `jeju-agent-submission.zip` (약 수십 MB)
- 인터넷: **없어도 됩니다.** 선택적 모델 대화나 실시간 허브 자료를 쓸 때만 필요합니다.

## 1. 압축 풀기

1. `jeju-agent-submission.zip` 을 바탕화면에 복사합니다.
2. 파일을 오른쪽 클릭 → **압축 풀기(모두 추출)** → **추출**을 누릅니다.
3. `jeju-agent` 폴더가 생깁니다. 폴더 안에 `실행.bat`, `python` 폴더, `app` 폴더, `web` 폴더가 있는지 봅니다.

> 폴더 경로에 한글이 있어도 됩니다. 다만 압축을 풀지 않고 zip 안에서 바로 실행하면 동작하지 않습니다.

## 2. 실행하기

1. `jeju-agent` 폴더의 **실행.bat** 을 두 번 누릅니다.
2. "Windows의 PC 보호" 창이 뜨면 **추가 정보** → **실행**을 누릅니다(서명하지 않은 배치 파일이라 뜹니다).
3. 검은 창에 `제주 동네 답사 에이전트가 켜졌습니다: http://127.0.0.1:8765/` 가 보이고, 몇 초 뒤 브라우저가 열립니다.
4. 브라우저가 안 열리면 Chrome/Edge 주소창에 `http://127.0.0.1:8765/` 를 적고 Enter 를 누릅니다.
5. "Windows 보안 경고(방화벽)" 창이 뜨면 **취소**를 눌러도 됩니다. 이 프로그램은 이 PC 안(127.0.0.1)에서만 열립니다.

끄려면 검은 창을 닫습니다.

## 3. 써 보기 (심사용 순서)

1. 아래 입력칸에 `제주에 작은 카페를 열고 싶어요` 를 적고 **보내기**.
2. 지역 선택지가 나오면 **아직 모름**을 눌러 전역을 유지합니다. 이어지는 선호 선택지 중 하나를 고르면 그 기준으로 후보를 계산합니다.
3. 상담에 표시된 후보 카드와 2D 지도의 번호·동네 이름이 같은지 확인합니다. 카드 하나를 누른 뒤 핀 하나를 누르면 선택한 동네가 카드와 지도 양쪽에서 강조됩니다.
4. 지도에서 동네를 고르면 해당 동네의 등록 점포·사업체 근거를 확인할 수 있습니다. 3D 거리 보기와 점포 상세는 별도 지도 기능에서 이용할 수 있습니다.

## 4. 모델 대화 켜기 — 선택

키가 없어도 로컬 상담과 화면 선택지를 이용할 수 있습니다. 모델을 연결하면 자유 문장 해석을 사용할 수 있으며 인터넷과 해당 공급자 키가 필요합니다. 기본 공급자는 OpenAI이고, Gemini를 고르면 실행 인자로 `--provider gemini`를 지정합니다.

1. `jeju-agent` 폴더의 `.env.example`을 복사해 이름을 `.env`로 바꿉니다.
2. 기본 OpenAI 경로에는 `OPENAI_API_KEY=`, Gemini 경로에는 `GEMINI_API_KEY=` 뒤에 받은 키를 넣습니다. Gemini를 쓸 때는 `실행.bat --provider gemini`로 실행합니다.
3. 키가 없거나 인터넷이 막혀 있어도 모델을 쓰지 않는 상담 경로로 진행합니다. 센터 자료 이용 중에는 `자유대화끄고실행.bat`을 사용합니다.

비밀 키는 `.env`에만 두고 ZIP, 화면 캡처, 공개 기록에 넣지 않습니다. 데이터 경계와 모델로 보낼 수 있는 정보는 [상담 API 계약](agent-contract.md)과 [데이터 활용 명세](데이터활용명세.md)를 따릅니다.

**센터 자료를 다루는 PC에서는 `자유대화끄고실행.bat`으로 켜세요.** 이 파일은 키가 있어도 모델·허브 API를 부르지 않습니다.

### 카카오 온라인 지도 켜기 — 선택

카카오 지도를 온라인 바탕 지도로 쓰려면 인터넷 연결과 카카오 JavaScript 키가 필요합니다. `.env.example`을 `.env`로 복사한 뒤 `KAKAO_MAP_JS_KEY=`에 발급받은 **JavaScript 키**를 입력하세요. REST 키나 Admin 키는 사용하지 않습니다. 키가 없거나 서버를 오프라인으로 실행하면 기존 자체 지도를 계속 쓸 수 있습니다. 제한 상담에서는 키를 브라우저에 보내지 않고 카카오 SDK를 불러오지 않습니다. 키는 `.env`에만 두고 ZIP이나 화면 캡처에 넣지 마세요.

## 5. 상담 기준과 지도 근거 확인

1. 지역 질문에서 `아직 모름`을 고르고 선호 질문에서 `생활시설 주변`을 선택합니다. 이것이 A 기준입니다. 상담 답변의 후보 카드에 있는 순번과 생활시설 근거를 확인합니다.
2. 같은 상담의 입력칸에 `동종 가게 비중이 낮은 곳을 더 중요하게 봐 주세요.`라고 입력해 전송합니다. 이것이 B 기준으로 바꾸는 사용자 요청입니다. 같은 업종 비중과 전체 점포 분모가 카드 이유에 표시되고, 실제 자료에서 순위와 근거가 A와 달라지는지 확인합니다. 2025-09-18 카페 자료의 예는 A `노형동 → 이도2동 → 연동`, B `연동 → 일도2동 → 도두동`입니다.
3. 지도를 휠로 확대하거나 축소해도 후보 카드의 수·순번·근거·집계 숫자는 바뀌지 않습니다. 지도 범위만 달라지며, 화면 밖 핀이 잠시 보이지 않을 수 있습니다.
4. 지도 아래 `동네 선택`에서 `조천읍`을 선택하고, 조천읍 안의 조사 지점(위도 33.542, 경도 126.669)을 지도에서 누릅니다. `300m`와 `500m`를 각각 눌러 실제 반경 집계를 확인합니다. 제주데이터허브 793 상가 자료의 기준일이 2025-09-18일 때 300m는 카페 12곳/음식 점포 130곳(9.2%), 500m는 카페 22곳/음식 점포 217곳(10.1%)입니다. 이는 행정동 전체가 아니라 직선 반경의 등록 점포이며, 반경이 경계를 넘어도 포함합니다.
5. 같은 상담에서 `조천읍 누가 오가나요?`라고 물어 읍면동 인구 근거를 확인합니다. 관측 자료가 있으면 화면에 표시된 읍면동 범위·자료 출처·기준일을 함께 읽습니다. 현재 오프라인 묶음에는 승인된 583 저장 스냅샷이 없으므로 자료를 받을 수 없으면 `관측 자료가 없습니다`와 같이 표시하며, 0명으로 간주하지 않습니다. 읍면동 집계는 조사 지점 앞을 지난 사람 수가 아닙니다.

## 6. 문제가 생기면

| 증상 | 해결 |
|---|---|
| 검은 창이 바로 닫힘 | 폴더를 압축 해제했는지 확인. `python\python.exe` 가 있는지 확인 |
| "주소가 이미 사용 중" | 이미 켜진 창이 있습니다. 그 창을 쓰거나 닫고 다시 실행 |
| 화면이 하얗게만 나옴 | Chrome/Edge 최신 버전인지 확인. 그래픽 가속(설정 → 시스템 → 그래픽 가속) 켜기 |
| 지도가 느림 | 오른쪽 위 **제주 전체**로 돌아간 뒤 다시 확대 |

## 7. 폴더 안 내용

| 이름 | 내용 |
|---|---|
| `실행.bat` | 프로그램 켜기 |

`README.md`, `app/`, `web/`의 화면·가공 자료·폰트와 오프라인 Three.js도 함께 들어 있습니다. 개발용 `build/`, `tests/`, `tools/`, 원자료, `.env`, 로그는 ZIP 허용 목록에 넣지 않습니다.

## 8. 릴리스 검증

이 절의 빌드 명령은 저장소 checkout에서 출시 담당자가 실행합니다. 생성된 ZIP 안에는 개발용 빌드·검증 도구가 없습니다.

### 오프라인 브라우저 E2E

저장소 checkout에서 개발·검수 담당자가 실행하는 검사입니다. 소스 서버를 임의의 루프백 포트로 띄우고 실제 `/` 상담 화면을 엽니다. 서버는 `offline=True`이며 브라우저가 루프백 이외로 요청하면 실패합니다. Python 3.10 이상, Playwright Python 패키지, 설치된 Chrome/Edge가 필요합니다. Playwright가 내려받는 별도 브라우저는 사용하지 않습니다. 개발 도구는 제출 ZIP에 넣지 않습니다.

```bash
python3 -m pip install playwright
python3 tools/notebook_shot.py --browser chrome --out shots/release-chrome
python3 tools/notebook_shot.py --browser msedge --out shots/release-edge
```

각 `report.json`과 화면 캡처는 문장 입력 → 실제 `아직 모름` 선택 → 화면에 제시된 선호 칩 선택 → 후보 카드/지도 핀의 순번·ID 일치 → 2번 카드와 1번 핀의 양방향 강조를 기록합니다. 결과는 같은 입력과 `web/data` 지문에서 재실행할 수 있습니다. 출력 폴더의 증거 파일은 덮어쓰지 않으므로 매 실행마다 새 폴더를 씁니다. 이 E2E는 소스의 상담·화면만 검증하며 패키지 ZIP이나 Windows 더블클릭을 검증하지 않습니다.

### 실제 clean Windows ZIP 게이트

macOS·Docker·Playwright 자동 실행은 Windows ZIP 실기동을 대체하지 않습니다. 아래는 일반 사용자 계정의 실제 Windows 10/11 x64 PC에서 같은 후보 ZIP으로 따로 수행합니다. 심사 브라우저 Chrome과 Edge가 설치돼 있어야 하지만, 테스트 동안 인터넷은 끕니다. 개발 Python·pip, API 키, 이전 압축 해제본은 없어야 합니다.

1. 패키징 PC에 Python 3.10 이상과 pip가 필요합니다. 온라인 빌드에는 python.org와 패키지 인덱스 접속이 필요합니다. 기존 `dist/` 밖의 새 경로로 빌드합니다. 빌더는 출력 디렉터리와 ZIP이 이미 있으면 덮어쓰지 않습니다.

   ```bash
   python3 build/package_windows.py --output-dir /tmp/jeju-release-candidate
   ```

   첫 온라인 빌드 출력의 `cache/python-3.12.10-embed-amd64.zip`과 `jeju-agent/wheels/`를 따로 보관하면, 다음 후보를 네트워크 없이 같은 입력 아티팩트로 만들 수 있습니다. 오프라인 빌드에는 이 공식 Python ZIP과 CPython 3.12 / Windows amd64 휠이 모두 필요합니다.

   ```bash
   python3 build/package_windows.py --output-dir /tmp/jeju-release-offline \
     --offline --python-archive /path/python-3.12.10-embed-amd64.zip \
     --wheelhouse /path/to/jeju-agent/wheels
   ```

2. 후보 ZIP의 파일명·크기·SHA-256을 외부 기록에 저장하고, Windows로 전달한 파일에서 아래 PowerShell 결과가 정확히 같은지 확인합니다.

   ```powershell
   Get-FileHash .\jeju-agent-submission.zip -Algorithm SHA256
   ```

3. Windows 탐색기에서 **모두 추출**을 눌러 한글이 포함된 새 경로에 풉니다. ZIP 안에서 직접 실행하지 않습니다. 추출 폴더에서 **동봉 Python**으로 두 SDK import를 확인합니다.

   ```powershell
   .\jeju-agent\python\python.exe -c "import sys, openai; from google import genai; assert sys.version_info[:3] == (3, 12, 10), sys.version"
   ```

4. 탐색기에서 `jeju-agent\실행.bat`을 실제로 두 번 눌러 켭니다. 검은 창이 유지되고, 브라우저가 자동으로 `http://127.0.0.1:8765/`를 열어야 합니다. 자동 열기가 실패하면 불합격입니다. 주소를 수동으로 입력하는 것은 진단만 할 때 쓰고 합격으로 바꾸지 않습니다.
5. 오프라인에서 새 Chrome 프로필과 새 Edge 프로필 각각으로 `http://127.0.0.1:8765/`을 엽니다. 각 브라우저에서 5절의 시연을 같은 상담 세션으로 끝까지 진행합니다. 카드와 지도 번호 연동, 선호 변경 전후 순서·근거, 줌 전후 집계 불변, 조천읍 동일 지점의 300m·500m 집계, 583 인구 조회 결과 또는 자료 없음 표시를 각각 캡처합니다. 1920×1080/100% 배율에서 잘림·겹침·콘솔 오류를 확인한 뒤 검은 창을 닫고 다시 더블클릭해 재실행합니다.
6. Windows 버전·일반 사용자 여부·네트워크 차단·Chrome/Edge 버전·1920×1080/100% 배율·실행 시각·담당자·ZIP SHA-256·동봉 CPython 버전·`docs/포함된_라이브러리.txt`의 자료 기준일/지문·SDK import·자동 열기/재실행·두 브라우저 결과를 기록합니다. 증거에는 키나 제한 자료를 넣지 않습니다.

위 수동 게이트에 실제로 필요한 PC·브라우저·실행 결과가 없으면 미통과로 남깁니다. E2E의 성공 보고서나 수동 주소 열기만으로 clean Windows 더블클릭 통과를 주장하지 않습니다.
